1. Introducción y Propósito del Proyecto
El presente proyecto consiste en el diseño y desarrollo de un sitio web temático dedicado a la
historia, estadísticas y controversias de los Mundiales de Fútbol. El objetivo principal de la
propuesta es consolidar los conocimientos técnicos adquiridos en materia de desarrollo
frontend, implementando una interfaz intuitiva, responsiva y estéticamente atractiva que
funcione como un repositorio de consulta para los entusiastas del deporte rey.
2. Organización del Trabajo y División de Roles
Para optimizar los tiempos de entrega y garantizar la calidad del producto final, el desarrollo del
proyecto se dividió de manera equitativa bajo la siguiente estructura de roles:
● Maquetación y Estilos (HTML y CSS): Encargado de la estructura semántica de todos
los documentos, la implementación de layouts avanzados mediante Flexbox y CSS Grid,
la definición de la paleta de colores global, y la creación de efectos visuales interactivos
como transiciones y estados hover.
● Contenido e Identidad Visual (Información e Imágenes): Encargado de la
investigación histórica, redacción de los textos analíticos y de controversias, recopilación
de datos estadísticos para el palmarés, y la selección y optimización de las portadas y
recursos gráficos del sitio.

4. Decisiones de Diseño y Especificaciones Técnicas
El apartado estético se gestionó de manera centralizada en un archivo style.css. Se priorizaron
las siguientes técnicas de desarrollo:
● Paleta de Colores: Basada en tonos púrpura (#5d009b y #7d2ae8) combinados con
detalles en oro (#ffc402) para transmitir prestigio y dinamismo.
● Diseño Responsivo: Implementación de flex-wrap: wrap en el menú superior para
asegurar su correcta visualización en dispositivos móviles, junto con un sistema Grid
dinámico (auto-fit) para la galería de imágenes.
● Experiencia de Usuario (UX): Inclusión de transiciones fluidas en los elementos
interactivos y un sistema de anclas internas combinadas con la propiedad scroll-behavior:
smooth para agilizar la lectura de contenidos extensos.
5. Conclusión
La metodología de trabajo adoptada permitió integrar de manera armónica el diseño técnico y
la riqueza del contenido. El resultado es un sitio web que no solo cumple con los estándares de
programación requeridos, sino que también ofrece una navegación cómoda y un alto valor
informativo para el usuario final.
